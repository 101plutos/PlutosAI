# Documentation Hub

This directory contains the core blueprints for building an AI-native family office and asset management firm. Each subfolder includes principles, controls, reference architectures, and implementation checklists.

## Structure

- `compliance`: Policies, procedures, risk framework, registers, and control mapping
- `security`: Security architecture, identity/IAM, secrets, vendor risk, IR/BCP
- `data`: Lakehouse, governance, catalog/lineage, quality, retention/privacy
- `ai-ml`: ML platform, evaluation/guardrails, responsible AI, model lifecycle
- `ops`: Investment operations, reconciliation, cash/fees, valuation controls
- `infrastructure`: Environments, IaC patterns, CI/CD, observability
- `client`: CRM schema, onboarding workflow, reporting/portal
- `org`: Org design, hiring plan, RACI templates
