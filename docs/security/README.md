# Security Architecture

Zero-trust, cloud-first security with automation and auditable controls.

## Pillars
- Identity and Access Management (least privilege, JIT/JEA)
- Secrets Management (KMS/HSM, rotation, no-secrets-in-repo)
- Network and App Security (mTLS, WAF, SAST/DAST)
- Data Security (classification, tokenization, row/column ACLs)
- Endpoint and Device Posture (MDM, EDR, disk encryption)
- Vendor/SaaS Risk and Third-Party Assessments
- Incident Response and Forensics (tabletops, RTO/RPO)

## Baselines
- Centralized logging and SIEM with detections
- Automated evidence capture for audits
- Key management, backup/restore drills
